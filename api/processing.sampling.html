processing.sampling module¶

Shared IDW / mesh sampling helpers for production probe scripts.

processing.sampling.idw_interpolate_vectors(values, distances, *, k, epsilon, on_node_epsilon)[source]¶

Inverse-distance-weight interpolate scalar or vector field values at a probe.

Inputs:

  • values – Per-node field samples (scalar or 3-vector components) [field units].

  • distances – Probe-to-node distances matching values rows [m].

  • k – Number of nearest neighbors for the IDW stencil.

  • epsilon – Softening length for IDW weights [m].

  • on_node_epsilon – Exact-hit distance threshold [m].

Outputs:

tuple – (interpolated_value, diagnostics) with IDW support metadata.

Parameters:

  • values (ndarray)

  • distances (ndarray)

  • k (int)

  • epsilon (float)

  • on_node_epsilon (float)

Return type:

tuple[ndarray, dict[str, Any]]

processing.sampling.idw_weights(distances, *, epsilon, on_node_epsilon)[source]¶

Build IDW weights or detect an exact mesh-node hit for probe sampling.

Inputs:

  • distances – Neighbor distances from probe to mesh nodes [m].

  • epsilon – Softening length added to distance before squaring [m].

  • on_node_epsilon – Distance below which the probe is treated as on-node [m].

Outputs:

tuple – (weights, exact_local_index, diagnostics); weights is None on exact hit.

Parameters:

  • distances (ndarray)

  • epsilon (float)

  • on_node_epsilon (float)

Return type:

tuple[ndarray | None, int | None, dict[str, Any]]

processing.sampling.select_nearest_indices(distances, k)[source]¶

Select the k nearest mesh-neighbor indices for IDW support.

Inputs:

  • distances – Full set of probe-to-node distances [m].

  • k – Requested neighbor count (clamped to available nodes).

Outputs:

np.ndarray – Local indices of the k nearest neighbors (unordered partition).

Parameters:

  • distances (ndarray)

  • k (int)

Return type:

ndarray
