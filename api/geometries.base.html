Bases: object

Declares a named geometry parameter with bounds and UI metadata.

Inputs:

  • name – Parameter identifier used in .geo templates [dimensionless].

  • description – Human-readable meaning of the parameter [dimensionless].

  • default_value – Numeric value when unset [matches unit].

  • min_value – Inclusive lower bound, if any [matches unit].

  • max_value – Inclusive upper bound, if any [matches unit].

  • unit – Physical unit label such as m or deg [dimensionless].

  • step – Suggested UI increment [matches unit].

  • decimals – Digits retained when writing template values [dimensionless].

  • read_only – Whether the GUI should forbid edits [dimensionless].

Outputs:
