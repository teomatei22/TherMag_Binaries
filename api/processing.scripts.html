processing.scripts package¶

Standalone ParaView/matplotlib post-processing scripts for TherMag runs.

Inputs:

None – package of CLI/script modules staged into run directories.

Outputs:

module – Contour/vector maps, probes, generate_plots, and sweep_plot helpers.
