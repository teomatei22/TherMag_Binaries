domain.sweep module¶

Typed sweep configuration for geometric parameter studies.

class domain.sweep.SweepConfig(swept_parameter, observables, lower_coefficient, upper_coefficient, coefficient_step)[source]¶

Bases: object

Coefficient range and observables for sweeping a geometric parameter in FEM runs.

Inputs:

  • swept_parameter – Name of the geometry parameter being swept (e.g. L).

  • observables – Ordered observable names to extract per run.

  • lower_coefficient – Lower multiplicative coefficient for the sweep.

  • upper_coefficient – Upper multiplicative coefficient for the sweep.

  • coefficient_step – Step between consecutive coefficients.

Outputs:

SweepConfig – Immutable geometric parameter-sweep configuration.

Parameters:

  • swept_parameter (str)

  • observables (tuple[str, ...])

  • lower_coefficient (float)

  • upper_coefficient (float)

  • coefficient_step (float)
