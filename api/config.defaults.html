config.defaults module¶

Validated access to user-editable application defaults.

class config.defaults.ApplicationDefaults(default_threads, temperature, drivers, driver_runtime, time_dependent, electric_bc, solver, sweep, bc_defaults, physics_constants)[source]¶

Bases: object

Application defaults loaded from JSON.

Inputs:

  • default_threads – Default worker/thread count for application runtime.

  • temperature – Thermal temperature defaults [K].

  • drivers – Mapping of driver name to DriverDefaults.

  • driver_runtime – Transient timestepping and output intervals defaults.

  • time_dependent – Time-dependent duration and period defaults.

  • electric_bc – Electric Dirichlet BC defaults [V].

  • solver – MPI process and stage timeouts defaults.

  • sweep – Parameter-sweep coefficient and bounds defaults.

  • bc_defaults – SIF boundary-condition default mapping.

  • physics_constants – Named physics constants (e.g. vacuum permittivity).

Outputs:

ApplicationDefaults – Immutable validated defaults tree from JSON.

Parameters:

  • temperature (TemperatureDefaults)

  • drivers (Mapping[str, DriverDefaults])
