processing.scripts.geometry_contract module¶

Canonical geometry metadata (family/variant/radii) shared by sphere-family post-processing.

class processing.scripts.geometry_contract.GeometryContract(family, variant, domain_radius_m, body_outer_radius_m, layer_interface_radius_m, cavity_radius_m)[source]¶

Bases: object

Frozen dataclass of geometry family, variant, and characteristic radii [m].

Inputs:

  • family – Geometry family string (sphere, prism, cylinder, …).

  • variant – Topology variant (full, hollow, layer_over_*).

  • domain_radius_m – Outer simulation-domain radius [m].

  • body_outer_radius_m – Conductor outer radius for spheres [m].

  • layer_interface_radius_m – Optional layer interface radius [m].

  • cavity_radius_m – Inner cavity radius for hollow variants [m].

Outputs:

GeometryContract – Immutable geometry metadata for probe/map scripts.
