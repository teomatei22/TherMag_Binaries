config.settings module¶

Runtime settings, tool discovery, and dependency checks for TherMag.

class config.settings.Settings(platform=<factory>, tools=<factory>, default_runs_dir=<factory>, default_threads=<factory>, post_processing_timeout=<factory>)[source]¶

Bases: object

Process-wide settings including tool paths, runs directory, and timeouts.

Inputs:

  • platform – OS platform string (e.g. linux, win32).

  • tools – Resolved paths to Gmsh, Elmer, MPI, and ParaView tools.

  • default_runs_dir – Default directory for simulation run outputs.

  • default_threads – Default worker/thread count from application defaults.

  • post_processing_timeout – Post-processing stage timeout [s].

Outputs:

Settings – Process-wide runtime settings with detected tool paths.

Parameters:

  • platform (str)

  • tools (ToolPaths)

  • default_runs_dir (Path)

  • default_threads (int)

  • post_processing_timeout (int)

class config.settings.ToolPaths(gmsh=None, elmergrid=None, elmersolver=None, elmersolver_mpi=None, mpiexec=None, pvpython=None)[source]¶

Bases: object

Resolved filesystem paths to external FEM and post-processing tools.

Inputs:

  • gmsh – Path to the Gmsh executable, or None if not found.

  • elmergrid – Path to ElmerGrid, or None if not found.

  • elmersolver – Path to serial ElmerSolver, or None if not found.

  • elmersolver_mpi – Path to MPI ElmerSolver, or None if not found.

  • mpiexec – Path to mpiexec/mpirun, or None if not found.

  • pvpython – Path to ParaView pvpython, or None if not found.

Outputs:

ToolPaths – Container of discovered external tool executable paths.

Parameters:

  • gmsh (Path | None)

  • elmergrid (Path | None)

  • elmersolver (Path | None)
