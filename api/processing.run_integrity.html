processing.run_integrity module¶

Append concrete run-integrity evidence to logs without aggregate status.

processing.run_integrity._log_path(cwd)[source]¶

Resolve and ensure the run-integrity log file path under the run directory.

Inputs:

cwd – FEM run working directory containing logs/ [path].

Outputs:

Path – Absolute path to logs/run_integrity.log (parent created if missing).

Parameters:

cwd (str | Path)

Return type:

Path

processing.run_integrity.append_run_integrity(cwd, check_name, detail)[source]¶

Append one timestamped integrity check line to the run log.

Inputs:

  • cwd – FEM run working directory [path].

  • check_name – Short check identifier (e.g. solver_completion).

  • detail – Free-text evidence for the check.

Outputs:

None – Appends a UTC-stamped TSV line to run_integrity.log.

Parameters:

  • cwd (str | Path)

  • check_name (str)

  • detail (str)

Return type:

None

processing.run_integrity.log_geometry_interpretation(cwd, family, variant)[source]¶

Record interpreted geometry family and hollow/layer variant for the run.

Inputs:

  • cwd – FEM run working directory [path].

  • family – Geometry family (cylinder, prism, sphere).

  • variant – Topology variant (full, hollow, layer_over_*).

Outputs:

None – Appends a geometry_interpretation integrity line.

Parameters:

  • cwd (str | Path)

  • family (str)

  • variant (str)

Return type:

None

processing.run_integrity.log_solver_completion(cwd, *, return_code, all_done)[source]¶

Record Elmer/solver exit evidence and fail on unclean completion.

Inputs:

  • cwd – FEM run working directory [path].

  • return_code – Process return code, or None if unknown.

  • all_done – Whether the solver emitted an ALL DONE / success marker.

Outputs:

None – Logs completion; raises RuntimeError when exit is unclean.

Parameters:

  • cwd (str | Path)

  • return_code (int | None)

  • all_done (bool)

Return type:

None

processing.run_integrity.log_time_coverage(cwd, source, times, *, expected_time_dependent, n_steps)[source]¶

Record and validate probe/time-series coverage against VTU steps.

Inputs:

  • cwd – FEM run working directory [path].

  • source – Probe or script name used as the check key prefix.

  • times – Sampled physical times written by the probe [s].

  • expected_time_dependent – True when the run has multiple VTU steps.

  • n_steps – Number of VTU timesteps expected for unique-time coverage.

Outputs:

None – Logs coverage detail; raises RuntimeError if coverage is insufficient.

Parameters:

  • cwd (str | Path)

  • source (str)

  • times (Iterable[float])

  • expected_time_dependent (bool)

  • n_steps (int)

Return type:

None
