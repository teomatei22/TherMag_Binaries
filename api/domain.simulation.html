class domain.simulation.SimulationConfig(base_type='full', driver_type='steady', simulation_type='steady', outer_material_model='simple', outer_material_name='', is_twolayer=False, inner_material_model=None, inner_material_name=None, temperature=<factory>, electric_bc=<factory>, time_dependent=None, solver=<factory>)[source]¶

Bases: object

Full FEM case config: materials, thermal/electric BCs, driver, and solver.

Inputs:

  • base_type – Geometry/base case type label (e.g. full).

  • driver_type – Thermal driver kind (steady, harmonic, sawtooth).

  • simulation_type – steady or time_dependent simulation mode.

  • outer_material_model – Constitutive model name for the outer material.

  • outer_material_name – Display name of the outer material.

  • is_twolayer – Whether an inner material layer is present.

  • inner_material_model – Optional constitutive model for the inner material.

  • inner_material_name – Optional display name of the inner material.

  • temperature – Thermal BC temperatures and optional frequency.

  • electric_bc – Electric Dirichlet BC configuration.

  • time_dependent – Transient settings when simulation_type is time-dependent.

  • solver – MPI process counts and stage timeouts.

Outputs:

SimulationConfig – Immutable full FEM case configuration.

Parameters:
