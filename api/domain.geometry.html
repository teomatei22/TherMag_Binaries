domain.geometry module¶

Geometry specification and spatial probe points for FEM post-processing.

class domain.geometry.GeometrySpec(name, geometry_type, parameters=<factory>, variant='full', template_file=None)[source]¶

Bases: object

Named geometry type, parametric dimensions, and optional Gmsh template.

Inputs:

  • name – Human-readable geometry case name.

  • geometry_type – Geometry family identifier (e.g. cylinder, sphere).

  • parameters – Parametric dimensions keyed by name [m or dimensionless].

  • variant – Geometry variant label (default full).

  • template_file – Optional path to a Gmsh .geo template.

Outputs:

GeometrySpec – Immutable named geometry specification for FEM cases.

Parameters:

  • name (str)

  • geometry_type (str)

  • parameters (dict[str, float])

  • variant (str)

  • template_file (Path | None)
