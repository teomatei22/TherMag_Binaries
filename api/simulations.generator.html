_generate_scalar_current_body_force(body_force_num, seebeck)[source]¶

Emit isotropic Seebeck body-force Current Density / SourceCurrent terms.

Combines Potential Flux from the OhmicCurrent FluxSolver with Temperature Flux from the SeebeckCurrent FluxSolver scaled by a scalar Seebeck coefficient.

Inputs: body_force_num: Elmer Body Force index to write [dimensionless]. seebeck: Isotropic Seebeck coefficient [V/K].

Outputs: str: Complete Body Force N ... End block for the SIF.

Parameters:

  • body_force_num (int)

  • seebeck (float)

Return type:

str

_generate_tensor_current_body_force(body_force_num, geometry_shape, s_par, s_perp)[source]¶

Emit anisotropic Seebeck body-force terms via shape-aware MATC.

Uses generate_tensor_vector_product so J = PotentialFlux + S grad(T) with the same cylinder/prism/sphere Seebeck tensor orientation as material blocks.

Inputs:

  • body_force_num – Elmer Body Force index to write [dimensionless].

  • geometry_shape – cylinder, prism, or sphere [dimensionless].

  • s_par – Parallel/radial Seebeck principal value [V/K].

  • s_perp – Perpendicular/tangential Seebeck principal value [V/K].

Outputs:

str – Complete Body Force N ... End block for the SIF.

Parameters:

  • body_force_num (int)

  • geometry_shape (str)

  • s_par (float)

  • s_perp (float)

Return type:

str

generate(base_type, driver, outer_material_model, outer_material_params, inner_material_model=None, inner_material_params=None, driver_params=None, air_params=None, output_path=None, geometry_shape='cylinder', bc1_potential=None, bc2_potential=None)[source]¶

Generate a complete coupled thermoelectric-magnetic Elmer SIF.

Inputs:

  • base_type – Mesh topology selecting base template and BC/body IDs.

  • driver – Steady/harmonic/sawtooth driving schedule.

  • outer_material_model – Constitutive model for the outer conductor.

  • outer_material_params – Outer material property map.

  • inner_material_model – Inner conductor model for layered topologies.

  • inner_material_params – Inner material property map.

  • driver_params – Optional temperatures/runtime; defaults if omitted.

  • air_params – Required Air material property map.

  • output_path – Optional filesystem path to write the SIF.

  • geometry_shape – Shape used for anisotropic tensor orientation.

  • bc1_potential – Optional electrode electric potential if set [V].

  • bc2_potential – Cold electrode electric potential if set [V].

Outputs:

str – Fully substituted SIF source text.

Parameters:

  • base_type (SifBaseType)

  • driver (DriverType)

  • outer_material_model (MaterialModel)

  • outer_material_params (dict[str, Any])

  • inner_material_model (MaterialModel | None)

  • inner_material_params (dict[str, Any] | None)

  • driver_params (DriverParams | None)

  • air_params (dict[str, Any] | None)

  • output_path (Path | None)

  • geometry_shape (str)

  • bc1_potential (float | None)

  • bc2_potential (float | None)
