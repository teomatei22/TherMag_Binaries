simulations.tensor_utils.generate_cylinder_tensor(par, perp, prop_name)[source]¶

Emit an Elmer SIF anisotropic tensor block for cylinder geometry.

Inputs:

  • par – Parallel principal conductivity/Seebeck value [SI].

  • perp – Perpendicular principal value [SI].

  • prop_name – Elmer property name such as Heat Conductivity [dimensionless].

Outputs:

str – SIF lines defining prop_name(3,3) via MATC.

simulations.tensor_utils.generate_prism_tensor(par, perp, prop_name)[source]¶

Emit an Elmer SIF anisotropic tensor block for prism geometry.

Inputs:

  • par – Parallel principal conductivity/Seebeck value [SI].

  • perp – Perpendicular principal value [SI].

  • prop_name – Elmer property name such as Electric Conductivity [dimensionless].

Outputs:

str – SIF lines defining prop_name(3,3) via MATC.

simulations.tensor_utils.generate_sphere_tensor(par, perp, prop_name)[source]¶

Emit an Elmer SIF anisotropic tensor block for sphere geometry.

Inputs:

  • par – Parallel (tangential) principal conductivity/Seebeck value [SI].

  • perp – Perpendicular (radial) principal value [SI].

  • prop_name – Elmer property name such as Seebeck Coefficient [dimensionless].

Outputs:

str – SIF $ function plus prop_name(3,3) MATC call (≤127 chars).

simulations.tensor_utils.generate_tensor_block(geometry_shape, prop_name, par, perp)[source]¶

Dispatch tensor-block generation by conductor geometry shape.

Inputs:

  • geometry_shape – cylinder, sphere, or other (prism) [dimensionless].

  • prop_name – Elmer property name for the tensor [dimensionless].

  • par – Parallel principal value [SI].

  • perp – Perpendicular principal value [SI].

Outputs:

str – Shape-appropriate anisotropic SIF property block.

simulations.tensor_utils.generate_tensor_vector_product(geometry_shape, par, perp)[source]¶

Emit MATC expression with shape-aware Seebeck anisotropy.

Inputs:

  • geometry_shape – cylinder, prism, or sphere [dimensionless].

  • par – Parallel Seebeck principal value [V/K].

  • perp – Perpendicular Seebeck principal value [V/K].

Outputs:

tuple[str, str, str] – MATC expressions for the three Cartesian product components (Jx_seebeck, Jy_seebeck, Jz_seebeck).
