simulations.material_params module¶

Convert material records into Elmer SIF generator parameter dicts.

simulations.material_params._require_tensor(material_name, attribute, tensor)[source]¶

Require a 3x3-style tensor sequence with at least five entries.

Inputs:

  • material_name – Material label used in error messages.

  • attribute – Property attribute name being validated.

  • tensor – Flattened tensor values; index 0 is parallel, 4 perpendicular.

Outputs:

Sequence[float] – The same tensor when it has length >= 5.

Parameters:

  • material_name (str)

  • attribute (str)

  • tensor (Sequence[float] | None)

Return type:

Sequence[float]

simulations.material_params.build_material_params(material, model)[source]¶

Build validated SIF generator parameters for a material/model pair.

Inputs:

  • material – Material record exposing name and properties [mixed SI].

  • model – Material model enum or string (simple, anisotropy, …) [dimensionless].

Outputs:

dict[str, Any] – Parameter map consumed by SifGenerator material blocks.

Parameters:

  • material (Any)

  • model (Any)

Return type:

dict[str, Any]
