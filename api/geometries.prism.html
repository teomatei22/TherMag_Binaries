geometries.prism module¶

Rectangular prism conductor geometries with hollow and layered variants.

class geometries.prism.PrismGeometry(variant, template_dir=None)[source]¶

Bases: BaseGeometry

Gmsh rectangular prism with end faces as hot/cold and air sphere.

Inputs:

  • variant – Topology selecting solid/hollow/layered templates.

  • template_dir – Optional directory containing .geo templates [path].

Outputs:

PrismGeometry – Configured geometry with physical volume/surface IDs.

Parameters:

  • variant (PrismVariant)

  • template_dir (Path | None)
